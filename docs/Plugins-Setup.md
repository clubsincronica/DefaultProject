# Obsidian Plugins Setup Guide

This guide explains the recommended community plugins for the Club Sincrónica Obsidian vault.

## Installing Plugins

1. Open Obsidian Settings (Ctrl+,)
2. Navigate to **Community plugins** → **Browse**
3. Search for the plugin name below
4. Click **Install**, then **Enable**

## Recommended Plugins

### 1. Dataview
Query and display data from your notes using SQL-like queries. Use for daily note summaries, content calendars, and dynamic dashboards.

### 2. Calendar
Visual calendar view in the sidebar. Quick navigation to any daily note and creation of new ones.

### 3. Excalidraw
Whiteboard diagrams. Use for storyboard layouts, pipeline flowcharts, and visual planning.

### 4. Templater
Advanced templating engine. Use for daily note templates with Kin data, content scaffolds, and automated frontmatter.

### 5. Daily Notes
Built-in daily notes support (enabled as core plugin, but the community version adds configuration options). Configure the daily notes folder and template in settings.

### 6. Graph Analysis
Enhanced graph view with community detection and clustering. Useful for mapping connections between content, concepts, and brand elements.

## Configuration

After installing, configure each plugin:

- **Dataview**: Enable JavaScript queries for advanced use cases
- **Calendar**: Set daily notes folder to match your preferred location
- **Templater**: Set template folder (e.g., `templates/`)
- **Daily Notes**: Set daily notes format to `YYYY-MM-DD`
